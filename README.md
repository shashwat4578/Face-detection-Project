# Face-detection-Project
This project aims to differentiate input images and tell either it is face or not face based on input set provided. The model was achieved by using both forward and backward propagation

# Forward Propagation
Forward propagation is essential for making predictions in neural networks. It calculates the output of the network for a given input based on the current values of the weights and biases. The output is then compared to the actual target value to calculate the loss, which is used to update the weights and biases during the training process.

# Backward Propagation
Backpropagation is a technique used in deep learning to train artificial neural networks particularly feed-forward networks. It works iteratively to adjust weights and bias to minimize the cost function. In each epoch the model adapts these parameters reducing loss by following the error gradient.
